# 用一个 HTML 交付可走预览

复制 [preview.html](../assets/preview.html)，另存为本次项目的 HTML。双击即可在浏览器查看虚构的双室示例。通常只需修改 `<script type="application/json" id="layout">` 中的数据即可交付首版。HTML 内有平面、可旋转的剖切模型、实际门洞、家具碰撞、键盘移动和双指触屏操作。示例使用浏览器自带的 WebGL 和 Canvas 2D。

## 填写户型

坐标采用米，`x` 向图右、`z` 向图下，高度从地面向上量。用标注尺寸分别校准横纵比例，并保留一个可再次辨认的坐标原点。

| 字段 | 填写方式 |
| --- | --- |
| `name`、`height` | 页面标题和室内净高。净高为演示取值时，在交付说明里写明。 |
| `rooms` | 每项填 `name` 和 `rect:[左,上,宽,深]`。矩形的并集形成地面。L 形房间可拆成同名的相邻矩形。室外平台加 `outdoor:true`。 |
| `walls` | 按两端点 `a:[x,z]`、`b:[x,z]` 填写水平或垂直墙。按全部房间的共享边界每段只画一次。 |
| `open` | 每一个洞口写成 `[起点距 a 的距离,洞宽,窗台高,洞顶高]`。门从地面起，高窗保留窗下墙。洞口要落在本墙段内。 |
| `items` | 每项填底部矩形 `rect`、顶底之间的 `height`、可选底标高 `bottom`。身体高度内的大件产生碰撞。不挡人的装饰可设 `solid:false`。 |
| `color` | 房间、墙、家具的颜色用六位十六进制，例如 `#8e9d83`。 |
| `start`、`look` | 两个不同的地面坐标。前者是人站的位置，后者是面朝的点。要从门外进屋，须在门外画出一块相连的平台，并在墙上留出相应洞口。 |

模板仅演示单层、直角墙与基本陈设，墙厚为 0.12 m。一段外墙上有落地封窗时，应给不能走通的玻璃加碰撞。斜墙、楼梯、抬高地面或需要精确贴图的项目，可选用能表达这些结构的几何实现，仍按实际入口检查通行。正式的四季氛围与可逆滚动见[漫游与实测](interaction-and-checks.md)。

## 发出首版

在交付文件里点「走进去」，从入户平台走进第一个主要房间，再转头看刚穿过的门。电脑用 W A S D 移动、拖动环顾，手机可用摇杆移动、另一根手指环顾。先把这个版本的 HTML 或可打开的链接发给用户，说明已经可试走的空间和仍按估值的尺寸。原委托还包括精装或源码时，继续完成这些内容。
